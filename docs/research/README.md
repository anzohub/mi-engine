# Research & Experiments

This directory is designated for technical investigations, research spikes, benchmarks, and exploratory notes.

## Guidelines

- Document exploratory work, technology evaluations, and performance benchmarks here.
- Outcomes and prototypes in this directory serve as inputs for technical discussion; they do not automatically constitute accepted architectural decisions.
- When an investigation leads to a permanent architectural direction, formalize the outcome through an Architecture Decision Record in `adr/`.
