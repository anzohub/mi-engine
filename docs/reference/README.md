# Reference

This directory serves as the repository boundary for stable reference material across `mi-engine`.

## Scope

- **Public API Contracts**: Formal interfaces and signatures for published packages.
- **Data Schemas**: Asset definitions, project manifest formats, and serialization contracts.
- **CLI Specifications**: Command-line interface syntax, parameters, and flags.
- **Generated Documentation**: Automated API references derived from codebase source declarations.

Generated reference documentation is produced by automated toolchain tasks and must not be edited manually.
