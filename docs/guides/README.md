# Guides & Recipes

This directory contains practical, task-oriented guides and step-by-step
recipes for working with `mi-engine`.

## Purpose

Guides provide concrete solutions for specific tasks, such as creating
custom components, configuring render passes, importing assets, managing shared
dependencies, or updating repository tooling.

Detailed guides will be added alongside the implementation of corresponding
features and repository workflows.

## Available Guides

- [Adding a Feature](adding-a-feature.md): Choose an owner, preserve runtime
  and editor boundaries, and validate a new capability without premature
  packages or plugin infrastructure.
- [Dependency Management & Tooling Updates](dependency-management.md): Manage
  shared dependency versions with pnpm catalogs and safely update Angular,
  TypeScript, Vite, Vitest, and Vite+ when their compatibility requirements
  differ.
