# Design Assets & Artifacts

This directory contains versioned design deliverables and token contracts for `mi-engine`.

## Sources of Truth

- **Figma**: The primary visual and design source of truth for UI layouts, components, and artboards.
- **Git Repository**: Tracks versioned token definitions and static reference exports for code integration and automated pipelines.
- **`design/figma/`**: Intentionally omitted. Raw binary design canvases and design file backups are hosted directly on Figma rather than checked into the Git tree to keep the repository lightweight and avoid competing sources of truth.

## Subdirectories

- **`tokens/`**: Normalized design token contracts consumed by application and editor packages.
- **`exports/`**: Static visual assets, icons, and diagrams exported for traceability and implementation handoff.
